# WordPress-like Static Site for GitHub Pages

A fully functional WordPress-like blogging system that runs entirely on GitHub Pages with **no server required**! 

## 🚀 Quick Start

Simply open `index.html` in your browser or deploy to GitHub Pages - it works immediately!

## ✨ Features

- 📝 Full post management (create, edit, delete)
- 🎨 Responsive design
- 🔍 Real-time search
- 🏷️ Tag system
- 💾 Export/Import posts
- 🆓 100% free hosting on GitHub Pages
